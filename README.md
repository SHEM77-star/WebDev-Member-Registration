# WebDev Member Registration System

## Project Overview

The WebDev Member Registration System is a web application developed for SPI 2201 – Web Application Development I. It allows users to register members, validate submitted information, and manage a dynamic list of registered members.

## Technologies Used

- HTML5 – webpage structure and registration form
- CSS3 – styling, responsive layout, and dark theme
- JavaScript – DOM manipulation, form validation, and event handling

## Features

- Member registration form with four fields
- JavaScript form validation and field-specific error messages
- Automatic clearing of validation errors when fields are corrected
- Dynamic display of registered members
- Automatic member counter updates
- Individual member removal
- Registration success message
- Automatic form reset after successful registration
- Dark Mode and Light Mode toggle
- Responsive layout for smaller screens

## How to Run the Application

1. Download or clone this repository to your computer.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the member details and click **Register Member**.

No additional packages or installation are required.

## Testing

The application can be tested by submitting empty fields, entering invalid information, registering valid members, removing members, checking the member counter, and switching between light and dark themes.
